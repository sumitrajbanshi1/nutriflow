# 🥗 NutriFlow — Weekly Meal Tracker & Planner

NutriFlow is a minimalist, responsive web application designed for family meal planning and meal prep tracking. Built with pure HTML, CSS, and vanilla JavaScript, it allows users to keep track of prepped meals throughout the week and automatically resets weekly progress.

---

## ✨ Features

- **Weekly Meal Tracking:** Tick off prepped meals (Breakfast, Lunch, Dinner) across all 7 days.
- **Auto-Reset Mechanism:** Tracks weekly completion and resets automatically every Monday morning.
- **Grocery List Generator:** Collects all ingredients from the weekly plan into a copyable list.
- **Dark / Light Mode:** Built-in theme switcher supporting system preference detection (`prefers-color-scheme`).
- **Print Friendly:** Dedicated print layout CSS for printing physical meal plans.
- **Local Persistence:** Completion state and theme choices persist across browser sessions using `localStorage`.

---

## 🛠️ Built With

- **HTML5 & CSS3:** Semantic markup and CSS variables for theme management.
- **JavaScript (ES6+):** Pure vanilla JavaScript without external dependencies.
- **Google Fonts:** Featuring *Fraunces*, *Inter*, and *Caveat*.
